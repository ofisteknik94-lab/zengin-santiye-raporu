# Zengin İzolasyon Günlük Şantiye Raporu

Bu paket GitHub Pages'e topluca yüklenmek üzere hazırlanmıştır.

## Yükleme
1. ZIP dosyasını bilgisayarınıza çıkarın.
2. GitHub deposunda **Add file > Upload files** seçin.
3. ZIP içindeki dosyaların tamamını (klasörün kendisini değil) depo ana dizinine sürükleyin.
4. `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg` ve `README.md` dosyalarının kök dizinde olduğundan emin olun.
5. **Commit changes** ile yüklemeyi tamamlayın.

Bu sürümde personel/çalışma ve malzeme metinleri PDF'de otomatik satır kaydırır; metin kutuları içeriğe göre büyür. Service worker önbellek sürümü de yenilenmiştir.

Not: Uygulama raporları sunucuya kaydetmez; PDF cihazda oluşturulur ve paylaşılır.
