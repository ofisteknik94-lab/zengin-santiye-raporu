# Zengin İzolasyon Günlük Şantiye Raporu

GitHub Pages için hazır statik web uygulaması.

## Yayınlama
1. GitHub'da yeni bir public repository oluşturun.
2. Repository adı örneğin `zengin-santiye-raporu` olsun.
3. Bu klasördeki dosyaların tamamını repository kök dizinine yükleyin.
4. Repository > Settings > Pages bölümüne gidin.
5. Build and deployment altında `Deploy from a branch` seçin.
6. Branch olarak `main`, folder olarak `/ (root)` seçip Save'e basın.
7. GitHub'ın verdiği Pages adresini açın.

Raporlar sunucuya kaydedilmez. PDF cihazda oluşturulur ve telefonun paylaşım menüsü üzerinden gönderilir.
